Protection / الحماية

Uses local domain lists. No browsing history is uploaded. First-party ads and some video ads are not covered.

Sources, licenses and limitations

Downloads / التنزيل

Existing filenames get a numbered suffix. Files never open automatically. WebView2 keeps its own visible download interface.

Family Protection / قفل الأطفال

Family mode restricts internal settings, private-window and developer-tool commands. Existing web tabs are closed on activation. Camera/microphone in the embedded WhatsApp surface are denied while family mode is active. Device administrators and other browsers are outside this lock.

Parent PIN & performance

Tabs reload when reactivated. Active, pinned, audible, captured, private, embedded WhatsApp and form-filled pages are excluded. If page inspection fails, the tab is kept. No discarding while downloads are in progress.

Changes are local to this Windows user.
