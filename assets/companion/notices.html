Sources, privacy and limitations

Local filtering

MaenBrowser bundles reviewed snapshots from StevenBlack hosts for advertising/tracking/mixed threats and adult domains, and Université Toulouse Capitole (UT1) for violence/aggressive domains. Attribution, original source comments, license information and snapshot hashes are included in the installation's filters folder.

Domain filtering cannot distinguish all individual pages, videos or posts on a shared domain. Adult and violence categories can contain mistakes. Parents can add explicit allow and block entries. Only-parent-approved-sites mode provides a more restrictive boundary.

Turning off the ad switch disables that mixed advertising/tracking domain list. It does not disable Family Protection, TLS validation, sandboxing or Windows security controls.

Privacy and permissions

No Maen account, telemetry endpoint or remote AI service is added. Native control requests are intercepted locally. The bundled extension needs tab, download, storage and page-inspection permissions for its controls, and extension-management permission to disable other extensions in family mode. User-requested text reading and idle-tab checks run locally.

Settings use Windows DPAPI and a salted PBKDF2-HMAC-SHA256 parent PIN. This is a browser-level parental control, not an operating-system security boundary against the same Windows user or an administrator. Another browser, deleting the profile, reinstalling or altering application files is outside this protection.

Compatibility

Third-party Chromium extensions use Chrome Runtime's extension management. Not every Chrome or Edge extension or store installation flow is guaranteed. Extensions do not automatically apply inside embedded WebView2 pages. Legacy Manifest V2 support is not promised.

WhatsApp runs in WebView2 in normal windows. Private WhatsApp remains in private CEF so it cannot reuse the normal WebView2 login; media codecs may differ. DRM streaming, HEVC and hardware decoding depend on the engine, licensing and the device.

Source checks and CI smoke tests do not establish that this is the world's lightest browser. Comparable Windows RAM/CPU measurements and real-device media tests are required before such claims.
