# MaenBrowser Android

Android is planned as a separate native mobile target. The Windows CEF executable cannot
be converted into an Android APK.

The Android edition will preserve the MaenBrowser principles: lightweight UI, local-first
data, modern web compatibility, no mandatory Maen account, and no weakening of platform
security. A production Android implementation is not included in MaenBrowser 1.2.0.

Compatibility claims will only be made after a real Android build defines minSdk/targetSdk
and is tested on representative old and current Android devices.
