# بوابة جودة الأمن والأداء — MaenBrowser

## متطلبات ملزمة

1. **أمان ثابت**: لا تُضحّى Sandbox أو Site Isolation أو فحص TLS/Certificate من أجل توفير RAM أو CPU؛ لا تُستخدم إشارات `--no-sandbox`, `--disable-web-security`, `--ignore-certificate-errors` وغيرها في إصدارات الإنتاج.
2. **خفة على الأجهزة القديمة**: أوضاع UltraLite/Lite/Balanced/Performance من النسخة 1.9.6 تبقى متاحة. محرك قائمة المؤشرات يستعمل مقارنات محلية ضمن العملية الحالية، ولا يبدأ عملية أو خدمة خلفية منفصلة.
3. **الخصوصية**: لا تُرسل طلبات تصفح المستخدم أو بياناته لمركز فحص مركزي دون حاجة واضحة وسياسة معلنة؛ التشخيص الحالي عدّادات فقط.
4. **التوافق**: عدم الحظر الشامل للإعلانات عند `ads=false`. تشديد النوافذ قد يؤثر على مواقع تعتمد على نوافذ تلقائية؛ اختبار الاستخدام الفعلي شرط قبل الإصدار.
5. **التحديث الموثوق**: تحديث Chromium/CEF إلى إصدار آمن مدعوم ومتابعة WebView2 Runtime، مع مراجعة القوائم والمصادر وتوقيع حزم الإصدار.

## الأداء المقبول

ليس هناك رقم عالمي مضمون للأجهزة 2GB، ويجب تجنب وعود أداء غير مقاسة. خذ ثلاث عينات متطابقة على أجهزة حقيقية أو VM مواصفات فعلية مستقرة لكل سيناريو: بداية تشغيل باردة، 5 تبويبات عادية، صفحة إعلام/فيديو، تنزيل ملف، وضع خمول. قارن CPU، استهلاك RAM الكلي مع عمليات Chromium الفرعية، تأخير التنقل، وأخطاء الصفحات قبل وبعد تطبيق الحماية.

بوابة الدمج المقترحة: عدم قبول **تراجع مستمر وملحوظ** بسبب طبقة الحماية دون تفسير أو ضبط، وعدم إلغاء أي حد أمني لتحسين الأرقام. عند اكتشاف تراجع، حسّن بنية البيانات أو افصل الفحوص المكلفة عند الحاجة فقط، مع إبقاء فحص الطلبات الأساسي دائمًا.

## حماية إضافية من المواقع المخترقة — مُنفّذة في هذه الدفعة

- فحص منشأ التنزيل مقابل مؤشرات الخطر المعروفة حتى عند إيقاف مانع الإعلانات.
- تحذير إلزامي ونافذة حفظ للبرامج/السكربتات ذات الامتدادات عالية المخاطر.
- طلب تفعيل SmartScreen داخل واجهة WebView2 الاختيارية؛ عند دعم النظام لذلك.
- لا يوجد فحص ملفات شامل أو اكتشاف دقيق لكل ثغرات PHP؛ التفاصيل في `PHP_COMPROMISED_SITE_DEFENSE_AR.md`.

## المستقبل — غير منفَّذ في الحزمة

- تحديث مؤشرات أمان موقّع مع تحقق من SHA-256/توقيع الناشر ونسخة احتياطية قابلة للاسترجاع.
- محرك سمعة روابط اختياري بمزود مرخص ووضع احترام الخصوصية؛ لا تُفترض مجانية Safe Browsing لأي استخدام تجاري.
- التحقق من سمعة جميع تنزيلات CEF ومحتواها عبر مزود موثوق؛ والتناغم مع Windows Defender وMark-of-the-Web دون مضاد دائم. التأكيد المحلي للامتدادات الخطرة مُنفذ بالفعل.
- تدقيق CEF/API/WebView2 وService Workers وتحويلاتها على Windows، وإجراء fuzzing ومراجعة ثغرات مستقلة.
