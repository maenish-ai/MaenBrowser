# MaenBrowser — حماية مستقلة من هجمات AdFection (18 أكتوبر 2026)

## المبدأ

هذه طبقة **حماية أمنية دائمة**؛ وليست ميزة حجب إعلانات.

- `ads = false`: يُسمح بالإعلانات العادية، بينما تُرفض مؤشرات التجسس المحددة أدناه.
- `ads = true`: يعمل مانع الإعلانات بجانب الطبقة الأمنية، دون الاعتماد المتبادل.
- استثناءات مانع الإعلانات لا تتجاوز حماية البنية الهجومية المحددة.
- لا يوجد خيار لإيقاف العزل الأمني أو تعطيل هذه الطبقة من واجهة المستخدم.

## مصدر المؤشرات ونطاق الحظر

Citizen Lab (15 أكتوبر 2026)، تحقيق *Exposing AdFection*:
https://citizenlab.ca/research/how-discover-tech-turned-targeted-ads-into-a-pipeline-for-spyware/

1. حظر أسماء خوادم Candiru التي حدّدها البحث كـ validator أو Command & Control؛ وهي ستة أسماء مضمّنة مباشرة في الكود أيضًا إذا فشل تحميل ملف القوائم.
2. حظر **المسارات الدقيقة** `/getAd` و`/cplatform/getAd` في ثماني وجهات NOAS موثّقة من التحقيق؛ لا تحظر هذه الحماية كل محتويات النطاقات الإعلانية المجاورة.
3. عدم اعتبار كل نطاق يظهر في تقارير استهداف الإعلانات دليلًا على التخريب: لا يتم حظر Volasim أو Akedo أو MyIPInfo ولا نطاقات CDN المشتركة لمجرد ورود أسمائها في التحقيق.
4. قائمة `security-threats.txt` منفصلة عن `ads.txt`. تضم نسخة مكررة من نطاقات C&C المؤكدة ويمكن توسيعها فقط عبر إصدارات مراجَعة وموثقة. لا يوجد تحديث تلقائي غير موثوق.

**تنبيه مهم:** المؤشرات تاريخية، وقد تتغير الملكية أو الخوادم. ينبغي إعادة تقييمها دوريًا. لا يعني عدم ظهور نطاق في القائمة أنه آمن.

## تعديلات الحماية المدمجة

- **CEF native request filter**: استدعاء `SecurityThreatUrl()` أولًا في `protection::Block()` قبل قراءة إعداد `ads` أو `family` أو الاستثناءات.
- **Redirect interception**: إعادة فحص URL في `OnResourceRedirect()` وإعادة التوجيه إلى endpoint داخلي لا يرسل طلبًا لشبكة الإنترنت عند الحظر.
- **Popups**: إلغاء نوافذ CEF التي يبدأها JavaScript دون `user_gesture`؛ النوافذ الناتجة عن نقرة صريحة لمواقع HTTP(S) تظل متاحة عند عدم وجود خطر معروف، لتقليل مشاكل OAuth والدفع.
- **WebView2**: نافذة التوافق الاختيارية تستدعي `protection::Block()` في `WebResourceRequested` وتتحقق من النافذة الجديدة والأذونات، وبالتالي تستخدم المؤشرات الجديدة نفسها. يجب التحقق من سلوك service workers/redirects في نظام تشغيل فعلي.
- **واجهة المستخدم**: شارة الدرع تعبّر عن الاتصال بالحماية الأساسية. يبقى مفتاح مانع الإعلانات واضحًا ومنفصلًا داخل اللوحة.
- **التشخيص**: تعرض API `securityShieldEnabled`, `securityBlockedRequests`, `securityThreatDomains`, `securityListError`؛ لا يتم تسجيل URL ولا معرف المستخدم ولا المحتوى أو كلمات المرور.

## ما لا تدّعيه الحزمة

- ليست مضاد فيروسات شاملًا أو حلًا لكل ثغرات Zero-click/0-day.
- ليس هناك ضمان لمنع سكربت خبيث يعمل على نطاق جديد غير موجود في المؤشرات، أو ضمن موقع مخترق مشروع.
- الحظر على مستوى المتصفح لا يحمي برامج أخرى على الجهاز ولا يمنع اختراق Windows بحساب Administrator.
- لا تتضمن خدمة Google Safe Browsing ولا قاعدة سمعة سحابية ولا فحص الملفات تلقائيًا؛ إدراجها لاحقًا يتطلب دراسة الخصوصية والتوافق والترخيص وتقييم الأداء.
- لا تتضمن تحديثًا مضمونًا إلى أحدث محرك Chromium/CEF؛ تحديث المحرك له مسار مستقل إلزامي قبل إصدار نسخة عامة.
- الحزمة ليست مبنية كنسخة Windows Setup؛ ملف GitHub يظل مصدرًا، ويحتاج CI وتجارب تشغيلية.

## اختبارات إلزامية قبل دمج الإصدار

1. `python tools/run-checks.py` واختبارات C++20 المحمولة.
2. Build Release Windows x64 مع `USE_SANDBOX=ON` وCTest؛ مَنَع flag `--no-sandbox` والتأكد من TLS/site isolation.
3. عند `ads=false` و `family=false`: يسمح بإعلان اختبار عادي، ويحظر host Candiru والـ NOAS loader المحدد، بما في ذلك تحويل URL خبيث.
4. عند إضافة استثناء لموقع: لا يتجاوز هذا استثناء قواعد `security-threats.txt`.
5. Popup دون gesture ممنوع، والنقر الشرعي لفتح Google OAuth أو الدفع لا يتعطل دون داع.
6. WebView2: التأكد من اعتراض الموارد الخاصة بالنطاقات الممنوعة، والاستثناءات الممكنة من service workers وفق إصدار API.
7. تشغيل 2GB / 4GB / 8GB: قياس RAM وCPU والزمن لأول تحميل مقارنة بنسخة `main` نفسها، وتوثيق فرق الأداء والتراجع.
8. مراجعة قائمة المؤشرات قانونيًا وتشغيليًا، وتوقيع حزم التحديث وتشغيل فحوص أمنية للتبعيات قبل النشر.

## تحديث 22 أكتوبر 2026

أضيفت طبقة مستقلة لحماية تنزيل الملفات التنفيذية والبرامج النصية، مع طلب SmartScreen في WebView2؛ انظر `docs/PHP_COMPROMISED_SITE_DEFENSE_AR.md`. لا يغيّر ذلك طبيعة قائمة AdFection الضيقة ولا يجعل حجب الإعلانات إلزاميًا.
