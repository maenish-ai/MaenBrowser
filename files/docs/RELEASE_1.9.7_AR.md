# MaenBrowser 1.9.7 — إصدار إشعارات التحديثات والروابط وتسجيل الدخول

## التغييرات

- **إشعار بالتحديثات:** الإضافة المدمجة تفحص GitHub Releases الرسمي عند تشغيل المتصفح، ثم كل ست ساعات أثناء تشغيله. تفحص رقم الإصدار `MAJOR.MINOR.PATCH` ووجود ملف Setup مطابق للإصدار. يظهر إشعار مرة واحدة لكل إصدار مع رابط صفحة الإصدار الرسمية. **لا تنزّل ولا تثبّت أي ملف تلقائياً**، ولا تقبل إصدارات draft/prerelease أو إصداراً بلا Setup.
- **فتح الروابط:** روابط HTTP/HTTPS العادية الناتجة عن نقرة المستخدم في نافذة جديدة تنتقل إلى التبويب الحالي. نوافذ OAuth/SSO والدفع تُترك في Chromium حتى لا ينقطع `window.opener` أو تدفق تسجيل الدخول. الإضافة المدمجة لا تنقل نوافذ `popup` إلى تبويبات أخرى، كما تتعرف على عناوين مصادقة إضافية.
- **روابط callback:** استثناء `localhost` و`127.0.0.1` و`::1` من ترقية HTTP إلى HTTPS القسرية؛ هذا مهم لتسجيل الدخول الذي يتصل بخادم محلي لتطبيق خارجي. إذا لم يبدأ التطبيق المستقبِل خادمه المحلي، فالمتصفح وحده لن يتمكن من إصلاح `connection refused`.
- **إصدار GitHub:** عند دمج المشروع ودفع وسم `v1.9.7` يشغّل GitHub Actions بناء Windows واختباراته، ثم يرفع ملف `MaenBrowser-1.9.7-Setup.exe` إلى GitHub Releases فقط عند توفر CEF media runtime موثّق. لا يجوز نشر نسخة stock CEF preview بوصفها الإصدار الكامل.
- **تحديث المثبّت:** NSIS يحتفظ بملف المستخدم الشخصي خارج دليل التثبيت؛ التحديث ليس حذفاً للبيانات.

## النشر

1. ارفع الملفات المعدلة إلى `main` مع الحفاظ على المسارات، أو افتح Pull Request وادمجه بعد مراجعة الفروقات.
2. شغّل `python tools/run-checks.py` وافحص نتيجة Build MaenBrowser Windows Setup على Windows، بما فيها اختبارات CTest وتشغيل المتصفح.
3. جهّز الأسرار `MAEN_CEF_ARCHIVE_URL` و`MAEN_CEF_ARCHIVE_SHA256` لمحرك CEF الموثّق. لا تعتمد على `stock-CEF-preview` عند نشر نسخة كاملة.
4. بعد نجاح CI على المصدر، أنشئ الوسم وادفعه:

   ```bash
   git tag v1.9.7
   git push origin v1.9.7
   ```

5. تأكد من وجود Release منشور عام ومن وجود ملف `MaenBrowser-1.9.7-Setup.exe` بداخله. لا تكتفِ بملف Artifact المؤقت في Actions؛ إشعارات المستخدمين تعتمد على Releases المنشورة.

## حدود مهمة

- النسخ السابقة التي بُنيت مع `MAEN_ENABLE_UPDATER=OFF` ولم تكن لديها آلية اكتشاف Releases **لا يمكن جعلها تُبلغ المستخدمين رجعياً بمجرد نشر Release**. مستخدم الإصدار 1.9.6 يحتاج تثبيت 1.9.7 يدوياً مرة واحدة، وبعدها يحصل على إشعارات الإصدارات التالية.
- إشعار التحديث **ليس تحديثاً صامتاً أو تلقائياً**؛ أي تثبيت تلقائي يتطلب بنية توقيع وتوثيق مستقلة.
- لا يمكن ضمان عمل جميع أنظمة تسجيل الدخول الخارجية؛ بعضها يمنع المتصفحات المدمجة عمداً، وبعضها يتطلب بروتوكول تطبيق أو خادماً محلياً فعّالاً. اختبر خصوصاً Google/Microsoft/Claude/Cloudflare على جهاز Windows الحقيقي.
- التعديلات والاختبارات المحمولة لا تثبت نجاح بناء Windows/CEF ولا صلاحية كل موقع. لا تنشر قبل اجتياز اختبار Release الفعلي.
