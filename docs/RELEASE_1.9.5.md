# MaenBrowser 1.9.5 — تجربة توافق الفيديو

## ما تغيّر

- فتح الصفحة في نافذة WebView2 مستقلة تابعة للبرنامج، من قائمة النقر بالزر الأيمن أو Ctrl+Shift+M.
- خيط STA مستقل وحلقة رسائل خاصة بمحرك الفيديو، بدل الاعتماد على نوع خيط واجهة CEF أو نافذة رسمه الداخلية.
- إظهار المحرك عند إنشائه، دون انتظار اكتمال تحميل الموقع لإظهاره.
- مهلة بدء 45 ثانية، ورسالة MB-704، وزر إعادة محاولة ينشئ وحدة تحكم جديدة.
- تجاهل نتائج الإنشاء القديمة بعد الإغلاق أو إعادة المحاولة، وإغلاق نافذة الوسائط قبل إنهاء CEF.
- إبقاء تحويل المواقع التلقائي معطّلًا، مع المحافظة على إصلاح واتساب وتعديلات 1.9.4.
- السماح بالتحويلات داخل WebView2 مع عرض العنوان، واستمرار تطبيق فلاتر المتصفح وسياسة حماية الأسرة.

## الاستخدام

1. ارفع محتويات الحزمة كاملة إلى جذر المستودع، بما فيها `.github`.
2. شغّل **Build MaenBrowser Windows Setup**.
3. انتظر نجاح البناء و**Real WebView2 H264 playback test** ثم نزّل Setup وثبّته.
4. افتح الصفحة التي تحتوي الفيديو واضغط **Ctrl+Shift+M**. إذا استخدمت القائمة، انقر خارج مساحة المشغّل حتى لا تظهر قائمة الموقع بدل قائمة المتصفح.
5. شغّل الفيديو في النافذة الجديدة. قد يلزم تسجيل الدخول مجددًا لأن جلسة WebView2 منفصلة عن CEF.

## حدود هذه المرحلة

هذا مسار يدوي تجريبي، وليس إضافة ترميزات لمحرك CEF ولا إثباتًا بأن كل ملفات MP4 ستعمل. لا يتم نقل ملفات تعريف الارتباط من CEF، ولا يُتاح المسار من نافذة CEF خاصة. النافذة مخصصة للتشغيل؛ تنزيل الملفات ومنح الكاميرا والميكروفون غير متاحين فيها. استخدم التبويب الأصلي للتنزيل. لا تُعرض نتائج فحص CEF القديمة على أنها نتائج فحص WebView2.

## التحقق

نجحت الاختبارات المحلية الحالية (17 ملف اختبار JavaScript و3 برامج اختبار C++) وفحوص الحزمة والترميز. العينة المرفقة مصنوعة محليًا من نمط اختبار ونغمة، وأكد ffprobe أنها H.264 Constrained Baseline وAAC-LC.

اختبار Windows الجديد يشغّل **نافذة البرنامج نفسها**، ويتبع تحويل HTTP، ويتحقق من إطارات فيديو مفكوكة وتقدم الزمن ودعم AAC المعلَن. لم يُنفّذ هنا؛ هذه البيئة لا تشغّل تطبيق Windows. الاختبار مكتوم، لذلك تبقى تجربة الصوت المسموع وأزرار المشغّل والموقع المطلوب على جهاز المستخدم ضرورية. نجاح الاختبارات المحلية ليس تأكيدًا لنجاح بناء Windows أو إصلاح الفيديو الفعلي.
