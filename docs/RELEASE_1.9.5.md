# MaenBrowser 1.9.5 — تشغيل الوسائط المباشرة داخل التبويب

## ما تغيّر

- عند فتح رابط مباشر لملف فيديو أو صوت معروف الامتداد، يُعرض المشغل في سطح WebView2 مضمّن فوق مساحة الصفحة **داخل التبويب والنافذة نفسيهما**؛ لا تُفتح نافذة متصفح ثانية.
- يعمل WebView2 عند الحاجة فقط لصفحات الوسائط المباشرة، ويُغلق عند مغادرتها لتقليل استهلاك الذاكرة والعمليات على الأجهزة القديمة.
- تُوجَّه امتدادات MP4 وM4V وMOV وWebM وOGV وOGG وMPG وMPEG وMKV، إضافة إلى M4A وAAC. يعمل WebView2 بحسب دعم الترميز في WebView2 Runtime وWindows؛ لا يضمن هذا كل ملفات الفيديو.
- تبقى صفحات واتساب والمواقع الاعتيادية على محرك CEF. لا تُحوَّل تلقائيًا كل صفحة تحتوي فيديو H.264، لأن ذلك يتطلب ترحيل الصفحة كلها إلى محرك آخر وقد يؤثر على جلسات الدخول والحماية.
- تبقى فلاتر الحماية والتنقل المدمجة قائمة ضمن مسار WebView2. لا تُنقل ملفات تعريف الارتباط أو حالة تسجيل الدخول من CEF.

## الاستخدام

1. ارفع محتويات الحزمة كاملة إلى جذر المستودع، بما فيها `.github`.
2. شغّل **Build MaenBrowser Windows Setup**.
3. انتظر نجاح البناء و**Real WebView2 H264 playback test** ثم نزّل Setup وثبّته.
4. افتح رابط ملف MP4 أو H.264 مباشرًا في التبويب. ينبغي أن يظهر المشغل في التبويب نفسه. لاختبار فيديو داخل صفحة موقع، يبقى دعم CEF/الموقع/الترميز هو العامل الحاسم.
5. إذا استمر ظهور التحميل أو فشل الملف، اختبره أولًا برابط HTTPS مباشر صالح؛ فقد يتطلب الموقع جلسة الدخول، أو يعيد رابطًا منتهيًا، أو يرفض التشغيل المضمّن.

## حدود هذه المرحلة

هذه الميزة لا تضيف ترميز H.264 إلى CEF. تشغيل H.264 يعتمد على WebView2 Runtime ومكونات Windows المتاحة وترخيصها، وعلى استجابة الخادم (مثل MIME وطلبات النطاق) وصلاحية الرابط. لا يمكن ضمان كل MP4 أو كل موقع أو DRM. روابط بلا امتداد معروف، أو صفحات HTML التي تضمّن الفيديو، لا تُكتشف تلقائيًا كملفات مباشرة. التشغيل الخاص يبقى داخل CEF. التحقق من الاختبارات المحمولة لا يثبت نجاح بناء Windows أو التشغيل الفعلي؛ يلزم اجتياز بوابة Windows وتجربة الملف المستهدف.

## التحقق

شغّل الاختبارات المحلية المعتادة، ومنها `tests/media_policy_test.cpp` و`tests/video_controls_test.mjs`. يتضمن المستودع عينة H.264/AAC للاختبار. يجب أن يجتاز إصدار Windows اختبار التشغيل الفعلي قبل اعتباره مثبتًا.
