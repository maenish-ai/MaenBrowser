# MaenBrowser 1.9.5 — تشغيل H.264 داخل التبويب نفسه

## تشخيص إشارة Actions الحمراء

نجح إعداد CEF وبناؤه واختبارات C++ وتثبيت WebView2 Runtime. فشل اختبار `Real WebView2 H264 playback test` بعد 75 ثانية لأنه لم يتلقَّ أي نتيجة تشغيل من نافذة توافق WebView2 القديمة. لم يكن ذلك خطأ ترجمة C++، لكنه يعني أن الاختبار لم يثبت نجاح التشغيل، لذلك تخطّى CI إنشاء Setup. وكان الاختبار يفتح نافذة توافق منفصلة، لا يختبر طلب التشغيل داخل الصفحة نفسها.

## التغيير في مسار التشغيل

- أُوقف تحويل الوسائط إلى WebView2 حتى لا ينتقل التشغيل إلى محرك أو جلسة أخرى.
- الهدف تشغيل ملفات MP4/H.264 وعناصر `<video>` في CEF نفسه، داخل الصفحة والتبويب نفسيهما، مع الاحتفاظ بالملفات التعريفية وعناصر التحكم والامتدادات والحماية.
- إصدار CEF القياسي المجلوب افتراضيًا لا يوفّر دعم Chrome للترميزات الاحتكارية؛ لا يكفي تغيير HTML أو علم تشغيل لإضافة H.264 إليه.
- جعل Windows CI يرفض الرجوع الصامت إلى CEF القياسي: يلزم أرشيف CEF مخصص متوافق مع الإصدار ومبنيًا باستخدام `proprietary_codecs=true` و`ffmpeg_branding=Chrome`، مع علامة الإصدار وSHA-256 موثّقين.
- استُبدل اختبار النافذة المنفصلة باختبار تكامل يشغّل H.264/AAC في صفحة CEF فعلية ويتحقق من فك الإطارات وعناصر التحكم، إضافة إلى فتح MP4 مباشر داخل التبويب.

## ما يلزم قبل بناء Setup

1. تشغيل **Build CEF 152 Maen Media Runtime** على مشغّل Windows x64 المخصص. يتطلب بناء Chromium/CEF مساحة وذاكرة ووقتًا كبيرًا.
2. مراجعة ترخيص توزيع المكتبات الاحتكارية والالتزامات المحلية قبل نشرها؛ انظر [تفاصيل بناء CEF وترخيصه](CUSTOM_CEF_MEDIA_BUILD.md).
3. نشر أرشيف CEF الموثوق على عنوان HTTPS يمكن لـ GitHub Actions تنزيله.
4. إضافة سرَّي GitHub Actions للمستودع: `MAEN_CEF_ARCHIVE_URL` و`MAEN_CEF_ARCHIVE_SHA256`.
5. تشغيل **Build MaenBrowser Windows Setup**. يجب أن يجتاز اختبار التشغيل الحقيقي داخل CEF قبل إنشاء Setup.

## حدود التوافق والخفة

إعادة استخدام CEF تعني عدم تشغيل محرك فيديو ثانٍ لكل صفحة، ما يتجنب كلفة سطح WebView2 الإضافي أثناء الاستخدام العادي ويحافظ على صفحة الموقع وجلسة CEF. الأرشيف المخصص أكبر وقد يتطلب موارد بناء كثيرة؛ ولا يمكن ضمان تشغيل كل فيديو أو DRM أو كل جهاز، إذ يعتمد فك الترميز على الملف ونظام التشغيل/GPU وبرامج التشغيل. يجب قياس الأداء على الأجهزة القديمة قبل ادعاء تحسن محدد.

## التحقق

اختبارات Linux المحمولة تتحقق من سياسة الوسائط وواجهات التحكم والحزمة فقط؛ لا تثبت فك H.264 على Windows. اختبار Windows الجديد يتحقق من الملف التجريبي H.264 Constrained Baseline/AAC-LC داخل CEF، وليس من كل مواقع الفيديو. يبقى اختبار الموقع الفعلي والجهاز المستهدف ضروريًا.
