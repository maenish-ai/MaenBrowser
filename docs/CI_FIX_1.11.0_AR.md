# إصلاح إشارة GitHub Actions الحمراء — 1.11.0

الأساس: 9b6043aa577d0f0b1a7d12d43d084b34b15aec56
التشغيل الذي تم فحصه:
https://github.com/maenish-ai/MaenBrowser/actions/runs/41977189185

## السبب المثبت من السجلات

فشلت مهام Android الثلاث في android-actions/setup-android@v3 قبل بناء التطبيق.
القيمة الافتراضية للحزم هي tools platform-tools، لكن حزمة tools القديمة لم تعد
متاحة، وظهر الخطأ: Warning: Failed to find package 'tools'. ثم خرج sdkmanager
بالرمز 1. لا يتعلق هذا الخطأ بتشغيل الفيديو أو بكود Windows.

بناء Windows، الاختبارات الأصلية، اختبار H.264 الفعلي، وإنتاج مثبت Setup نجحت
كلها في التشغيل نفسه. علامة التشغيل العامة أصبحت حمراء بسبب مهام Android.

## التعديل

- تعيين الحزم صراحة في إعدادات SDK الثلاثة إلى:
  platform-tools platforms;android-36 build-tools;35.0.0
- تضمين مسار البناء الموقّع اليدوي لمنع تكرار الخطأ فيه.
- تثبيت بيئة مهام Android على Ubuntu 24.04 بدل ubuntu-latest المتغير.
- إبقاء اختبارات الأجهزة، Lint، التوقيع وحماية Windows كما هي.
- إضافة اختبار يمنع رجوع طلب حزمة tools في أي من المسارات الثلاثة.

هذه صيانة لبيئة البناء؛ رقم البرنامج يبقى 1.11.0.

## الرفع

فك ضغط MaenBrowser-1.11.0-CI-Fix-Changed-Files.zip وارفع محتوياته إلى جذر
المستودع مع استبدال الملفات. يجب رفع مجلد .github المخفي؛ يحتوي الملفين:
.github/workflows/android.yml
.github/workflows/android-signed-release.yml

ارفع أيضًا ملف الاختبار والتوثيق وملفات التحقق الموجودة في الحزمة. عند عمل
Commit على main يبدأ تشغيل جديد تلقائيًا. بديلًا عن ذلك، استخدم Full-Source.zip
من حزمة الإصلاح الجديدة لرفع المصدر الكامل.

## التحقق

نجحت فحوص المصدر والمنطق وYAML واختبار المسارات الثلاثة. جرى التحقق من أمر
SDK بالحزم المصححة محليًا وخرج بنجاح. يلزم تشغيل GitHub الجديد بعد رفع التعديل
لتأكيد نتيجة بيئة GitHub والمحاكي؛ لا نعتبر التشغيل القديم قد تغير إلى أخضر.
