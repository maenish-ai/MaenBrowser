# تقرير تسليم مصدر MaenBrowser 1.8.0

التاريخ: 2026-10-08. الحالة: نسخة تطوير تحتاج بناء واختبار على ويندوز.

## ما الذي تم عمله؟

أضيفت لوحة تحكم مدمجة بأيقونة درع، وتشمل تشغيل/إيقاف حجب نطاقات الإعلانات، استثناءات المواقع، إعدادات الأسرة برمز PIN، اختيار مجلد التنزيل أو السؤال عند كل تنزيل. أضيف البحث في التبويبات، تثبيتها وتجميعها، حفظ جلسات محلية بإجراء صريح، قارئ نصي وأدوات تنزيل وفحص للميديا. تفريغ التبويبات الخاملة يتجنب التبويب النشط والمثبت والمسموع والمكالمات والنماذج التي قد تحتوي على عمل غير محفوظ، مع فحوص محافظة إضافية.

قواعد الحماية تعمل في طبقة CEF الأصلية، ودمج واتساب يستخدم قواعد مماثلة داخل WebView2. الإعدادات محمية بـ Windows DPAPI، والتحقق من PIN يستخدم PBKDF2. لا يوجد تعطيل مقصود لصندوق Chromium الأمني أو عزل المواقع.

## الاختبار الفعلي

| الفحص | النتيجة |
|---|---|
| حدود النطاقات وتطبيعها ومنع مطابقة نطاق مشابه مزيف | ناجح محليًا |
| قواعد اختيار التبويبات للتفريغ واستبعاد الجلسات الخاصة | ناجح محليًا |
| JavaScript syntax، مراجع ملفات الواجهات، تطابق النسخة ومعرف الإضافة وبصمات القوائم | ناجح محليًا |
| بناء C++ الكامل بـ MSVC وربط CEF/WebView2 | لم ينفذ |
| تشغيل اختبار التكامل الجديد داخل المتصفح | لم ينفذ |
| تجربة الأيقونات والنوافذ والميديا فعليًا على ويندوز | لم تنفذ |
| قياس الذاكرة ومقارنة Chrome/Edge/Firefox | لم ينفذ |
| إنشاء وتجربة Setup جديد | لم ينفذ |

محاولة تشغيل بيئة واجهة محلية تعثرت بسبب منع socket في البيئة. محاولة فحص C++ بأدوات متقاطعة لم تكتمل بسبب غياب رؤوس Chromium المولدة؛ لذلك لا تعد نجاح بناء. اتصال GitHub أعاد 403: Resource not accessible by integration عند إنشاء فرع. لم يتم تعديل المستودع البعيد، ولم يتم تشغيل بناء ويندوز لهذه التغييرات.

## الوصول إلى Setup

1. فك ضغط حزمة المصدر. يحتوي مجلد MaenBrowser على المشروع كاملاً بما فيه .github.
2. ارفع **محتويات المجلد** إلى فرع development/1.8.0 أو طبّق التغييرات عبر Git. رفع ZIP كملف داخل المستودع وحده لا يبني المشروع.
3. من GitHub Actions شغّل Build MaenBrowser Windows Setup للفرع. يجب أن تنجح بوابات الفحص والبناء واختبار التكامل قبل إنتاج ملف Setup.
4. إذا فشل البناء، احتفظ بسجل أول خطأ لإصلاحه. لا تتجاوز الاختبار للحصول على Setup يبدو ناجحًا.
5. بعد النجاح حمّل artifact الخاص بـ Setup وجربه أولاً في حساب ويندوز تجريبي أو آلة افتراضية.

يمكن استكمال الخطوات مباشرة عندما يتاح اتصال GitHub يسمح بالكتابة إلى هذا المستودع. هذه الحزمة لا تتضمن ملف Setup، ولا تمثل نسخة إنتاج مكتملة.

## حدود مهمة لتقييم الميزات

- الخفة هدف قابل للقياس. تفريغ التبويبات وتقليل نشاط الخلفية لا يثبتان التفوق على كل المتصفحات. استخدم نفس الجهاز والمواقع والمحرك وتوقيت الانتظار للمقارنة. يشمل قياس واتساب عملية WebView2 الإضافية.
- الحجب يعتمد على نطاقات. إعلانات الطرف الأول وبعض إعلانات الفيديو قد لا تختفي. إيقاف الحجب يوقف القائمة المختلطة التي تتضمن بعض نطاقات التتبع/التهديد أيضًا؛ لا توجد هنا خدمة مستقلة كاملة لمكافحة التصيد.
- قفل الأطفال الافتراضي عند تفعيله يعتمد مواقع مسموحة يحددها الوالد. التصنيف بالاعتماد على قوائم وحدها غير شامل. المواقع المسموحة قد تعرض محتوى متغيرًا. SafeSearch مضاف لمسارات بحث محددة وليس لكل محرك بحث.
- يتم طلب تعطيل الإضافات الأخرى وإغلاق التبويبات المفتوحة عند تفعيل وضع الأسرة. لا يعاد تمكين إضافات كانت معطلة تلقائيًا. حساب ويندوز صاحب الصلاحيات يمكنه حذف ملف المستخدم أو تعديل التطبيق؛ لا توجد حماية على مستوى النظام من ذلك.
- إعدادات PIN لا تحمي من شخص يسيطر بالكامل على حساب ويندوز نفسه. حدود محاولات PIN حالياً داخل العملية وتُصفّر عند إعادة التشغيل.
- الإضافة المدمجة تعتمد تحميل Chrome Runtime للإضافات وسياسة تثبيت الأيقونة؛ يحتاج ذلك تأكيدًا فعليًا على CEF152. لا ادعاء بأن كل إضافات Chrome أو Edge تعمل. واجهات Store وAPI والخدمات المقيدة تُختبر لكل إضافة.
- H.264/AAC وDRM مثل Widevine ليست مضمونة في CEF الرسمي. WebView2 لواتساب لا يضيف دعم تلك الصيغ إلى جميع مواقع CEF. يتطلب دعم DRM/الترميزات المملوكة مسار توزيع وترخيص مناسبًا.
- قوائم الحجب لقطات بتاريخ إعداد الحزمة، بلا تنزيل خلفي للتحديثات. المصادر والتراخيص الأصلية وبصمات الملفات محفوظة داخل assets/filters. يجب مراجعة تحديثها قبل إصدار عام.
- مدير تنزيلات الإضافة يعرض تنزيلات CEF؛ تنزيلات WebView2 لها واجهته الخاصة.
- لا يوجد توقيع رقمي جديد ولا مسار تحديث تلقائي موقع مكتمل. لا تسوق النسخة على أنها أقصى مستوى أمان قبل اختبارها ومراجعتها وتحديث محركها.

## بوابة التجربة على ويندوز

اختبر تشغيل/إيقاف الحجب والاستثناءات؛ PIN الصحيح والخاطئ وإعادة التشغيل؛ المسموح والممنوع والنطاقات الفرعية والروابط الخارجية والنوافذ الخاصة؛ طلب أذونات الكاميرا والميكروفون؛ تنزيل عادي وblob وواتساب، إلغاء نافذة الحفظ وتعارض اسم ملف؛ بحث/تثبيت/إغلاق/استرجاع تبويب والجلسات؛ نموذج غير محفوظ وصوت ومكالمة قبل التفريغ؛ العودة من واتساب والرجوع/التقدم وتغيير الحجم؛ ترميزات الميديا وملفات فعلية؛ تحديث التثبيت مع بقاء الملف الشخصي؛ وكل أيقونة في لوحة التحكم.
