# MaenBrowser 1.8.4 — اتصال لوحة الحماية

الرسالة المصورة تعني أن اللوحة لم تستطع قراءة حالة خدمة الحماية. لا تثبت وحدها توقف الحجب الأصلي. علامة ON قد تكون حالة محفوظة قديمة؛ لذلك لم نعد نبقي حالة مؤكدة عند فشل القراءة.

## التعديل

- تسجيل معالج `https://maen.browser` المحلي عند تهيئة كل CefRequestContext، إضافة إلى السياق العام. الهدف تغطية اتصال service worker والسياقات المختلفة، دون إرسال بيانات التحكم للشبكة أو تخفيف التحقق من هوية الإضافة.
- مسار احتياطي لقراءة الحالة من إطار الإضافة إذا فشل الاتصال بالخدمة الخلفية. لا إعادة تلقائية لطلبات تغيير الإعدادات أو محاولات PIN، لتجنب تكرار عمليات ربما نُفذت.
- تحويل الشارة إلى `?` عند فشل اتصال النافذة؛ لا عرض ON قديم على أنه حالة مؤكدة.
- عرض رقم إصدار اللوحة وإصدار المتصفح عند الاتصال، ورمز تشخيص عند الفشل: PROTECTION_NETWORK أو PROTECTION_HTTP_403 أو PROTECTION_WORKER أو PROTECTION_RESPONSE. هذه معلومات تشخيص وليست سبباً لاستثناء موقع من الحماية.
- اختبار Windows يفتح لوحة الحماية فوق تبويب ويب عادي، بدلاً من الاقتصار على فتحها فوق صفحة الإضافة. بقي اختبار حجب طلب إعلان فعلي وإيقاف/تشغيل الإعدادات واختبار PIN موجوداً.

## التحقق والحدود

بناء 1.8.3 السابق نجح: https://github.com/maenish-ai/MaenBrowser/actions/runs/37896882053

اجتازت اختبارات JavaScript المحلية مسار القراءة الاحتياطي، ومنع تكرار الكتابة، والحفاظ على أخطاء PIN، ورموز HTTP، وصحة الحزمة والترجمات. بناء 1.8.4 وتجربة نافذة Windows ينتظران GitHub Actions. لم يُعد إنتاج عطل جهاز المستخدم محلياً، لذلك هذه معالجة لمسارات اتصال ناقصة وليست إثباتاً أن سبب الصورة حُسم.

الحزمة كاملة وتحتوي إصلاحات الأداء والتنزيلات والفيديو السابقة. بعد رفع محتوياتها وانتظار نجاح Actions يجب تنزيل وتثبيت **Setup 1.8.4** وإغلاق النسخة القديمة. رفع المصدر إلى GitHub لا يحدث البرنامج المثبت. بعد التثبيت يجب أن تظهر اللوحة **1.8.4**. إذا استمر الخطأ أرسل صورة يظهر فيها رمز الخطأ ورقم الإصدار، وجرب فتح «الإعدادات والعائلة» لتحديد ما إذا كان الفشل محصوراً في النافذة.

مرجع API: CEF `include/cef_request_context_handler.h` (OnRequestContextInitialized) و`include/cef_request_context.h` (RegisterSchemeHandlerFactory) في مصدر Chromium Embedded Framework: https://github.com/chromiumembedded/cef/tree/7977/include
