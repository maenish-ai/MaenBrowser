# حزمة MaenBrowser 1.13.0 المعدلة

حزمة واحدة تشمل المصدر والتعديلات والتقارير وأدوات البناء والتوقيع والاختبار. لم نرفع شيئًا إلى مستودع GitHub الخاص بك، ولم ننشئ فرعًا بعيدًا أو ريليس أو نشغّل Actions نيابةً عنك.

**حالة الإصدار:** مرشح بناء ومراجعة، وليس ريليس إنتاجيًا مكتمل الأمان. المحرك النشط ما زال CEF154؛ جُهّز مسار بناء واختبار CEF156، لكنه يحتاج Windows ومساحة SSD كبيرة. مفاتيح وهوية الناشر واختبارات الأجهزة الفعلية غير موجودة في هذه البيئة. لم نضع أرقام أداء أو ملفات محرك أو توقيعات وهمية.

- Full-Source.zip: فك الضغط لتحصل على المشروع كاملًا، بما فيه مجلد `.github`.
- Changed-Files-Upload.zip: التغييرات بالنسبة للمرجع الأصلي `e2692a82b018af5bd34a236787148f9ede49e8f2`، وتشمل تعديلات التدقيق السابق. راجع التعارضات إن تغيّر مستودعك بعد هذا المرجع.
- .patch: يُفحص بـ `git apply --check` أولًا على فرع محلي مستقل ثم يطبّق. لا يحتاج رفع المصدر من هذه المحادثة.
- SHA256SUMS.txt: للتحقق من اكتمال تنزيل الملفات.
- Android-TEST-ONLY.zip: APK تجريبي بمفتاح debug وAAB غير موقعة؛ ليست حزمة Play جاهزة للإنتاج. لا تحذف تطبيقك أو بياناتك لتجاوز اختلاف التوقيع.

GitHub لا يفك ضغط ZIP تلقائيًا إلى ملفات مشروع. فك الضغط وارفع الشجرة بمساراتها، أو استخدم GitHub Desktop/Git إذا تجاوز عدد الملفات حد رفع الويب؛ لا ترفع ZIP وحده وتتوقع بناء التعديلات الموجودة داخله.

التغييرات تشمل حفظ واسترداد الجلسات، استئناف التنزيل الأصلي، فرز وبحث التبويبات والإعدادات، مسار بيانات حماية موقعة ومحمي برمز الوالد، أدوات قياس Windows، إصلاح هوية الإصدار، وحفظ اختيار التبويب عند دوران Android. [الحالة المفصلة](IMPLEMENTATION_STATUS.md) و[الاختبارات](TEST_RESULTS_1.13.0.md) و[موانع الإنتاج](RELEASE_BLOCKERS.md).

لبيانات الحماية المباشرة: راجع SIGNED_SECURITY_DATA.md. المفتاح الخاص يبقى خارج المستودع، والسياسة تحمل المفتاح العام فقط. النشر الآلي لفرع البيانات معطّل افتراضيًا ولا يعمل بمجرد رفع المصدر. حزم المتاجر تحتاج هوية ومفاتيح حساب الناشر؛ راجع STORE_DISTRIBUTION.md.
