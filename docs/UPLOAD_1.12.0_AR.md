# رفع إصلاحات 1.12.0

1. استخدم Full-Source.zip للمصدر الكامل أو Changed-Files-Upload.zip لتحديث
   المستودع الحالي الذي يحتوي إصلاح CI الأخير (الأساس1216772).
2. فك الضغط وارفع المحتويات إلى جذر المستودع، بما فيها .github المخفي وassets
   وinstaller وsrc وtools وtests، مع استبدال الملفات. لا تكتفِ برفع ZIP كملف واحد.
3. اعمل Commit على main ليبدأ بناء GitHub. انتظر نجاح Windows وAndroid.
4. نزّل مثبت Setup1.12.0 من Artifacts لتجربة Windows. الوسمv1.12.0 ينشئ مسودة
   إصدار بعد اجتياز الاختبارات؛ النسخة الجديدة من Windows لم تُبنَ على هذه الآلة.

ما تغير: عربية المثبّت، وضوح صفحة البداية، تاريخ وساعة الجهاز، الطقس الاختياري،
فتح الروابط العادية في تبويب جديد داخل النافذة الحالية، وتحديث أدوات GitHub.

الطقس من MET Norway ومرخّص CC BY4.0 مع ذكر المصدر، ويسمح بالاستخدام التجاري.
لا تتطلب الخدمة مفتاح API مدفوعًا. يعرض المتصفح توقعات قد تختلف عن القياسات
المحلية. اختر مدينة أو اضغط استخدام موقعي وامنح إذن الموقع إن رغبت. عند التفعيل
تصل الإحداثيات وعنوانIP للمصدر، ويمكن إيقافه ومسح بياناته من زر إيقاف الطقس.

الساعة والتاريخ يتبعان إعدادات الجهاز والمنطقة الزمنية، ويعملان دون اتصال.
لا نستنتج موقع المستخدم منIP. اختيار مدينة للطقس لا يغيّر ساعة الجهاز.

شغّل رابطًا من واتساب بعد تثبيت التحديث: يفترض أن يبقى الشات مفتوحًا ويظهر
الرابط في تبويب آخر من النافذة ذاتها. احتُفظ باستثناءات نوافذ تسجيل الدخول والدفع
داخل الصفحات حتى لا تتعطل تلك الجلسات.

اختبارات المصدر وواجهة الصفحة وبناء Android نجحت هنا. فحص نص العربية داخل
مخرجات NSIS نجح بملفات اختبار مؤقتة، وليس بمثبت متصفح وهمي للتوزيع. يجب نجاح
تشغيل Windows الجديد على GitHub واختبار المثبّت الفعلي بعد الرفع.
