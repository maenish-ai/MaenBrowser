# عرض حجم MaenBrowser في تطبيقات Windows المثبتة

أضيف تسجيل `EstimatedSize` من الحجم الفعلي لمجلد التثبيت (بالكيلوبايت) في مفتاح إلغاء التثبيت تحت HKCU. يتم حسابه أثناء تشغيل Setup بعد نسخ الملفات، ولا يضيف عمليات خلفية للمتصفح ولا يغير الحماية أو الأداء.

## التحقق على Windows
1. ثبّت نسخة Setup الجديدة فوق النسخة السابقة بعد إغلاق المتصفح.
2. افتح Settings > Apps > Installed apps (أو Apps & features).
3. تأكد من ظهور الحجم بجانب MaenBrowser؛ قد تحتاج إغلاق الإعدادات وفتحها مجدداً.
4. تحقق من الإصدار والناشر وإزالة التثبيت.

الحجم المعروض تقدير لحجم الملفات المثبتة، وليس حجم ملف Setup المضغوط. لم يتم إجراء بناء Windows في بيئة إعداد هذه الحزمة.
