# خطة المتصفح وما نُفّذ في 1.11.0

1. **الخفة والأجهزة القديمة:** بقي اختيار الموارد تلقائيًا ومحافظًا، مع وضع أداء
   اختياري للأجهزة الحديثة. أضفنا الاستعادة التدريجية للجلسات. Android يستخدم محرك
   النظام بدل شحن محرك إضافي ويحدد عدد التبويبات الحية حسب الذاكرة. لا يمكن الحكم
   بأنه الأسرع دون قياسات على الأجهزة المقصودة. Android 10 هو الحد الأدنى؛ تشغيل
   أجهزة بأنظمة متوقفة أمنيًا ليس هدف إصدار آمن.
2. **الجلسات والوكلاء:** ملفات تعريف مسماة مستقلة لجلسات CDP المحلية؛ لا تُنسخ
   كوكيز المستخدم إلى الوكيل. استيراد/تصدير مجموعات التبويبات مع نسخة سابقة.
   تكامل YourAssistantAgent السابق يبقى مطلوبًا في مشروعه. Manus وChatGPT
   السحابيان يحتاجان دعم الاتصال بمتصفح خارجي من الجهة نفسها؛ تثبيت متصفحنا لا
   يحوّل جلساتهما السحابية تلقائيًا إلى الجهاز.
3. **الوسائط والمواقع والإضافات:** دعم Windows العامل لـH.264/AAC محفوظ. Android
   يستخدم دعم WebView والنظام والترميز العتادي المتوفر. MKV حاوية وليست ترميزًا،
   وHEVC وDRM يتطلبان دعمًا خاصًا. تطبيقات Adobe وOffice المكتبية لا تتحول إلى
   مواقع؛ مواقعها تحتاج اختبار تسجيل دخول وتحرير وتصدير. إضافات Firefox لا تعمل
   تلقائيًا في CEF، وAndroid WebView لا يوفر مضيف إضافات Chrome المكتبية.
4. **الأمان:** حماية تحميل DLL إضافية دون تعطيل sandbox أو GPU أو JIT، وتقرير
   دوري يقارن المحرك بمصادر رسمية. محرك Windows154 ما زال متأخرًا: لم نَدّعِ سد
   ثغرات Chromium التي تحتاج تحديث المحرك. Android يعتمد على تحديث WebView
   المثبت وتحديثات النظام؛ TLS يرفض الشهادات المعطوبة ولا يوجد جسر JavaScript أصلي.
5. **الإعلانات وحماية الأسرة:** قوائم محلية جاهزة، مع موارد توافق محدودة في
   Windows لتقليل كسر المواقع. لا توجد طريقة تضمن عدم اكتشاف كل المواقع للحجب.
   Android يضيف رمز مرور مشتقًا ومملحًا وتشفيرًا وتباطؤًا بعد المحاولات الفاشلة،
   ويحجب التصفح أثناء تحميل قوائم الأسرة أو تلف الحالة المحمية. هذا مرشح نطاقات،
   لا يفهم كل منشور داخل موقع مختلط المحتوى، وليس إدارة جهاز تمنع إزالة التطبيق.
6. **التسليم:** مصدر كامل، ملفات معدلة، patch، APK تجريبي وAAB غير موقع بعد نجاح
   البناء. إصدار GitHub مسودة تجريبية حتى اجتياز اختبارات Windows والأجهزة.
   إصدار Play يتطلب توقيع الناشر وبيانات المتجر؛ لا ترسل مفاتيح أو كلمات مرور.

## كيف اخترنا الأولويات من ملاحظات المستخدمين؟

راجعنا أمثلة علنية عن استهلاك الذاكرة وضياع الجلسات ومجموعات التبويبات. هذه
شكاوى ومراجع لتحديد الأولويات، وليست إثباتًا أن كل الأخطاء موجودة في متصفحنا.
النتيجة العملية: تحميل تدريجي، حماية المحادثات والنماذج من التفريغ، واسترجاع
آخر مجموعة جلسات سليمة. لا ننقل إصلاح Gecko إلى CEF كأنه إصلاح لنفس المحرك.
