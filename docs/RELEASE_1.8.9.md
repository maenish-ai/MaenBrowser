# MaenBrowser 1.8.9 — development source delivery

Base: https://github.com/maenish-ai/MaenBrowser/commit/5a4856ebb3094437869c2177457d74fab8a85dd0

## التغييرات المنفذة

- الإعدادات ← حول متصفح معن ← التفاصيل التقنية: إصدار البرنامج وCEF، محرك الوسائط، وضع Lite/Balanced/Performance، ذاكرة الجهاز، عدد المعالجات، ذاكرة العملية الرئيسية، ووقت المعالج التراكمي.
- تحديث المعلومات عند فتح الصفحة أو الضغط على التحديث فقط، دون مؤقت دائم أو فحص إنترنت خارجي.
- تقرير JSON قابل للنسخ مع حالة الحماية. بيانات الذاكرة والمعالج تخص العملية الرئيسية فقط وليست مجموع عمليات المتصفح. وقت المعالج ليس نسبة استخدام CPU.
- سجل أخطاء محلي محدود بآخر 50 حدثًا، دون عناوين المواقع أو أسماء الملفات أو رمز الوالدين. الكتابة بين صفحات متعددة best-effort وقد يفقد تحديث متزامن بعض الأحداث؛ ليس سجل تدقيق أمنيًا.
- رموز الوسائط MB-201 إيقاف، MB-202 تحميل، MB-203 فك ترميز، MB-204 مصدر غير مدعوم، MB-299 سبب غير محدد. هذه الرموز تخص صفحة فحص الوسائط؛ لا تدّعي تشخيص DRM أو كل فيديو على كل موقع.
- إعادة التحقق من نشاط التبويب وسياسة الاحتفاظ به والتنزيلات وتغيّر مدة الخمول قبل تحرير ذاكرته. تطبيق المدة المختارة وعدم الرجوع إلى 15 دقيقة أثناء الفحص النهائي.
- تنظيف مؤقت فحص الصفحة فور اكتمال الفحص.
- إضافة اختبارات الانحدار إلى GitHub Actions، وفحص بيانات التشخيص الأصلية ضمن اختبار Windows الحالي.

## ما حُفظ

بقي المحرك الأساسي CEF وWebView2 للوسائط عند الطلب. لم تُغيّر قوائم الحماية أو PIN/DPAPI أو إعدادات sandbox وعزل المواقع أو صلاحيات المواقع. وضع Lite الموجود أصلاً مستمر. لا يوجد ادعاء بقياس تحسن الأداء على جهاز قديم.

## الفحص المنفذ

نجحت محليًا اختبارات JavaScript الأربعة عشر، وفحص الحزمة والأصول والترجمة العربية والإنجليزية، واختبار ترميز الحزمة، واختبارا C++ لقواعد النطاقات وتوجيه الوسائط.

**لم يُبنَ ملف EXE ولم يُجرَ اختبار Windows/CEF/WebView2 في بيئة التسليم Linux.** أضيفت اختبارات Windows إلى مسار البناء، لكنها تنتظر التشغيل بعد رفع المصدر. لا تُعامل الحزمة كإصدار مثبت صالح للنشر قبل نجاح البناء والتجربة.

## الرفع والتجربة

1. فك ZIP وانسخ محتويات مجلد MaenBrowser-1.8.9 إلى جذر المستودع، بما فيها `.github` و`assets` و`src` و`tests`، أو ارفع التغييرات باستخدام Git. لا ترفع ZIP وحده وتتوقع أن يبني Actions محتوياته.
2. شغّل Build MaenBrowser Windows Setup من Actions. المصدر يشمل ملفات البناء والاختبارات، أما CEF وWebView2 SDK فينزلهما المسار الموجود.
3. بعد نجاح المسار نزّل Setup من Artifacts وجرّبه على ملف تعريف تجريبي.
4. افتح الإعدادات ثم حول متصفح معن، حدّث البيانات وانسخ التقرير.
5. اختبر تشغيل وسائط محلية، واتساب والصوت والكاميرا، التنزيلات، طلبات الصلاحيات، PIN وحماية الأطفال، وحجب نطاق اختباري.
6. على جهاز قديم قارن بدء التشغيل والذاكرة الكلية وCPU مع الإصدار السابق بنفس الصفحات. لا تعتمد على ذاكرة العملية الرئيسية وحدها.

لم تُرفع أي تغييرات إلى GitHub تلقائيًا. لم تتم إضافة محرك بديل أو ضمان توافق جميع الإضافات أو الوسائط. هذه حزمة مصدر كاملة بتطوير محدد وقابل للمراجعة، وليست تنفيذًا لكل الأفكار المستقبلية المذكورة في النقاش.
