# توافق YourAssistantAgent مع MaenBrowser

جهزنا تعديلين متوافقين معاً: MaenBrowser 1.10.0 وحزمة Companion Patch لمستودع
`maenish-ai/YourAssistantAgent`. لا ترفع ملفات Agent إلى مستودع المتصفح.

## السبب في عدم التوافق السابق

قائمة نوافذ Agent لم تتضمن MaenBrowser.exe، وطريقة Playwright المعتادة تستخدم
تشغيل Chrome عبر pipe، بينما المتصفح مبني على CEF. تعديل Agent يتعرف عليه
ويشغله بملف دخول مستقل في مجلد MaenBrowser فرعي داخل ملفات Agent ثم يتصل محلياً عبر CDP. يظهر خيار MaenBrowser في
إعدادات متصفح فيسبوك، واختياره الصريح لا يرجع تلقائياً إلى Chrome عند الفشل.

## الاستخدام

1. ابن وثبّت المتصفح الجديد من مستودع MaenBrowser.
2. فك حزمة YourAssistantAgent Companion Patch وارفع محتوياتها إلى مستودع
   YourAssistantAgent بالمسارات نفسها، ثم ابن وثبّت Agent المحدّث بإجراءاته الحالية.
3. اختر MaenBrowser في إعدادات المتصفح داخل Agent، أو حدد ملف MaenBrowser.exe
   كمتصفح مخصص. اختر الوضع المرئي؛ وضع headless غير مفعّل لهذا المسار.
4. افتح فيسبوك من Agent وسجّل الدخول يدوياً وأكمل 2FA/CAPTCHA بنفسك. ملف دخول
   Agent مستقل عن التصفح اليومي؛ لا تُنسخ كلمات المرور أو ملفات تعريف الارتباط.
5. استخدام البرنامج لا يمنح إذناً جديداً للنشر؛ بوابات موافقة Agent تبقى كما هي.

## الحماية

وضع التحكم الآلي اختياري، لا يبدأ مع التصفح العادي ولا يفتح منفذ تصحيح افتراضياً.
يستخدم loopback وملفاً مستقلاً ويحافظ على Sandbox. يُرفض عند تفعيل حماية الأسرة،
وتمنع منه تغييرات إعدادات الحماية. إذا تغيّرت إعدادات الحماية من متصفح عادي
تُغلق نوافذ Agent خلال فحص دوري يقارب ثانية؛ افتحه مجدداً بعد استقرار الإعدادات.
هذا يحمي من استخدام نسخة قديمة من سياسة الأسرة في عملية متصفح ثانية.

لا تُثبّت إضافة Browser Bridge تلقائياً. إن اخترت إضافتها الحالية يدوياً فهي
مسار منفصل حسب توثيق Agent ولا تنقل تسجيل الدخول إلى ملفه المُدار. لا يوجد
تجاوز لشروط تسجيل الدخول أو التحقق الثنائي. اختبر الربط الحقيقي على Windows؛
الاختبارات المحلية تحاكي حدود المتصفح ولا تثبت نجاح Facebook فعلياً.


## أدوات Agent أخرى

لأداة تدعم CDP شغّل `tools/start-agent-browser.ps1` باستخدام PowerShell 7.2+
على Windows. يفتح ملفاً مستقلاً ويطبع عنوان loopback وPID لعمليته فقط.
يمكن تحديد ExecutablePath وProfilePath وPort. يرفض المنفذ المستخدم ولا يتصل
بجلسة أخرى مصادفة. يُضمّن السكربت أيضاً داخل مجلد tools في التثبيت الجديد.
توصيل Playwright/Puppeteer عبر CDP يختلف عن طلب تشغيل المتصفح كـChrome عبر
pipe أو ChromeDriver؛ ليست كل أداة آلية متوافقة دون تكييف.
