# توافق أدوات الوكلاء مع MaenBrowser عبر CDP

يدعم MaenBrowser أدوات التحكم المتوافقة مع Chrome DevTools Protocol (CDP) عبر مشغّل محلي. يدعم ذلك أدوات متعددة بجلسات مستقلة، ولا يتطلب دمج ملفات الأداة داخل مستودع المتصفح.

## جلسة مستقلة لكل أداة متوافقة مع CDP

شغّل `tools/start-agent-browser.ps1` باستخدام PowerShell 7.2+ على Windows، واختر اسماً فريداً وثابتاً لكل أداة. مثلاً:

```powershell
pwsh -File .\tools\start-agent-browser.ps1 -SessionName manus
pwsh -File .\tools\start-agent-browser.ps1 -SessionName claude
pwsh -File .\tools\start-agent-browser.ps1 -SessionName myagent
```

كل اسم يحدد ملف تعريف مستقلًا ودائمًا تحت `%LOCALAPPDATA%\MaenBrowser\Agent User Data\<SessionName>`؛ لذلك لا تُشارك ملفات الارتباط أو التخزين المحلي مع تصفح MaenBrowser العادي أو مع جلسة أداة أخرى. الجلسات المسماة تحصل تلقائيًا على منافذ loopback مختلفة، ويطبع المشغّل JSON يتضمن `cdp` و`processId` و`sessionName` و`profilePath`. اضبط الأداة على الاتصال بعنوان `cdp` الذي أعاده المشغّل، ولا تفترض منفذًا ثابتًا. لا تشغّل نسختين بالاسم نفسه في الوقت نفسه؛ اترك عملية الجلسة قائمة لتحتفظ الأداة باتصالها.

للتوافق مع الإعدادات القديمة، `SessionName=default` يبقي ملف التعريف الافتراضي ومنفذ `9223`. يمكن تحديد `ExecutablePath` و`ProfilePath` و`Port` يدويًا عند الحاجة. يُضمّن السكربت في مجلد `tools` بالتثبيت الجديد.

المنفذ مربوط حصريًا بـ`127.0.0.1`، لكن CDP يمنح المتصل تحكمًا كاملًا بالمتصفح وبالجلسة المفتوحة؛ لا تكشفه على الشبكة أو الإنترنت، ولا تشارك عنوانه مع جهة غير موثوقة. تجنّب تسجيل الدخول إلى حساب شخصي في ملف أداة آلية ما لم تكن تقصد حفظه في ملفها المنفصل.

هذا المسار يعمل فقط مع أداة تتيح الاتصال بـCDP. تشغيل المتصفح كـChrome عبر pipe أو ChromeDriver لا يكافئ الاتصال بعنوان CDP. البرامج التي لا تتيح CDP تحتاج موصلًا خاصًا بها، ولا يمكن لهذا المشغّل ربط جلساتها الداخلية تلقائيًا.

## الحماية وحدود الأتمتة

وضع التحكم الآلي اختياري، ولا يبدأ مع التصفح العادي ولا يفتح منفذ تصحيح افتراضيًا. يستخدم ملفات تعريف مستقلة ويحافظ على Chromium Sandbox. يُرفض عند تفعيل حماية الأسرة، وتمنع منه تغييرات إعدادات الحماية. إذا تغيّرت إعدادات الحماية من متصفح عادي تُغلق نوافذ Agent خلال فحص دوري يقارب ثانية؛ افتح الجلسة مجددًا بعد استقرار الإعدادات.

لا تُثبّت إضافة Browser Bridge تلقائيًا. لا يوجد تجاوز لشروط تسجيل الدخول أو التحقق الثنائي أو بوابات الموافقة الخاصة بالأداة. الربط المحلي لا يمنح إذنًا جديدًا للنشر أو لإجراء تغييرات خارج المتصفح. يلزم اختبار التكامل الفعلي على Windows؛ اختبارات المصدر لا تثبت توافق كل أداة أو موقع.

## ملاحظات توافق

التحكم عبر CDP يختلف عن تشغيل Chrome عبر pipe أو ChromeDriver. ينبغي أن تتيح الأداة الاتصال بعنوان CDP الذي يخرجه المشغّل، مثل Playwright/Puppeteer عند دعم الاتصال بعنوان `connectOverCDP`. إذا كانت الأداة لا توفر نقطة اتصال CDP قابلة للضبط، يلزم تكييف خاص بها؛ لا توجد آلية عامة لربط الجلسات الداخلية لأي تطبيق تلقائيًا.
