# 1.8.7 — إصلاح فشل حفظ الإعدادات

مصدر التشخيص: https://github.com/maenish-ai/MaenBrowser/actions/runs/37967138715/job/113944193171

نجح بناء الإصدار 1.8.6 واختبارا C++، ثم فشل اختبار المتصفح برسالة:
`Checkbox save did not reach native protection`، حيث بقي الحجب مفعّلًا بعد محاولة إطفائه وحفظه.

السبب: الاختبار أنشأ رمز الوالدين ثم أوقف حماية الأسرة بالرمز الصحيح. بعدها أرسلت واجهة الإعدادات `family:false` عند حفظ تغيير الإعلانات، رغم عدم تغيير حماية الأسرة. الخادم المحلي يشترط الرمز عند وجود حقل family مع رمز محفوظ، فرفض العملية. كانت المشكلة في طلب الواجهة وليست في ترجمة كود C++.

التعديل: حذف حقل family من الطلب إذا كانت قيمته لم تتغير. يبقى إرساله عند تشغيل أو إيقاف حماية الأسرة، ويبقى التحقق الأصلي من الرمز داخل C++ دون تعديل. كل تغيير أثناء تفعيل حماية الأسرة لا يزال يتطلب الرمز.

أُضيف اختبار يغطي الحفظ العادي وتغييرات حماية الأسرة وتمرير الرمز. تأكدنا أنه يفشل على كود 1.8.6 وينجح بعد الإصلاح. احتُفظ باختبار ويندوز الذي اكتشف العطل، مع إضافة نص رسالة الواجهة لتشخيص أي فشل لاحق؛ لم يُلغَ الاختبار ولم تُخفَّف شروط نجاحه.

التحقق المحلي يشمل اختبارات JavaScript وفحص الحزمة والترجمة. يلزم رفع المصدر وتشغيل Actions للتحقق من النسخة الجديدة على ويندوز وإنشاء Setup. لا يوجد ادعاء بأن البناء الجديد نجح قبل تشغيله، ولا أن هذا الإصلاح يحل جميع حالات تشغيل الفيديو أو يثبت تحسن الأداء.

فك ضغط الحزمة وارفع محتوياتها إلى جذر المستودع مع الاستبدال، بما فيها `.github`. بعد نجاح Actions نزّل Setup الذي يحمل الإصدار 1.8.7.
