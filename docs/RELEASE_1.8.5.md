# MaenBrowser 1.8.5 — إصلاح اتصال الحماية

الصورة السابقة كانت تعرض `PROTECTION_UNKNOWN`. هذا يعني أن الواجهة التقطت خطأ غير مصنّف؛ لا يعني أن الحجب يعمل أو متوقف.

في هذه النسخة:

- يسجّل التطبيق نقطة التحكم المحلية عند تهيئة كل `CefRequestContext`، وليس السياق العام فقط؛ يغطي ذلك سياقات التبويبات وطلبات service worker.
- تتحقق الواجهة من شكل الحالة المستلمة (`ads` و`family` و`exceptions`) قبل عرض زر ON/OFF، حتى لا تعتبر استجابة ناقصة اتصالاً ناجحاً.
- فشل حفظ لغة الواجهة لا يحوّل اتصال الحماية إلى فشل.
- عند فشل قراءة الحالة تظهر رموز أدق مثل `PROTECTION_NETWORK` أو `PROTECTION_WORKER` أو `PROTECTION_RESPONSE`.
- لا تعاد كتابة إعدادات الحماية تلقائياً بعد فشل الاتصال، حتى لا تتكرر عملية PIN أو تغيير الإعلانات.
- اختبار Windows يفتح اللوحة فوق صفحة ويب عادية ويفحص القراءة الفعلية للحالة.

الفحوص المحلية نجحت. لم يُشغّل بناء 1.8.5 على Windows بعد، لذلك يجب انتظار GitHub Actions قبل اعتبارها نسخة تجربة. بعد التثبيت يجب أن يظهر رقم اللوحة `1.8.5`. إذا بقيت المشكلة، أرسل صورة رقم الخطأ الجديد أسفل زر Retry.

الحزمة تتضمن إصلاحات الأداء والتنزيل والفيديو السابقة. لا تعتمد على زر ON القديم؛ بعد التثبيت أغلق المتصفح بالكامل وافتحه من جديد.
