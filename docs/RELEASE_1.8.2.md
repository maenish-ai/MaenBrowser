# MaenBrowser 1.8.2 — إصلاح مسار الفيديو

## التغييرات

- فتح روابط HTTPS المباشرة المنتهية بـ MP4 / M4V / M4A / AAC في محرك Windows WebView2 داخل التبويب. لا يعمل المحرك عند بدء المتصفح ولا في الصفحات العادية؛ يُغلق عند مغادرة الصفحة أو إغلاق التبويب.
- مشغّل الملفات المباشرة يستخدم أدوات التشغيل والصوت والتقديم الأصلية، ويضيف اختيار سرعة التشغيل ورسائل عربية/إنجليزية للأخطاء. لا تشغيل إجباري ولا تنزيل تلقائي للملف بالكامل من كود المتصفح.
- زر «إظهار أدوات الفيديو» داخل نافذة الحماية يفعّل أدوات HTML5 في فيديوهات الصفحة والإطارات التي تسمح للإضافة بالوصول إليها. يُستخدم عند الحاجة؛ لا فحص مستمر لكل المواقع.
- التبويبات التي تستخدم محرك الوسائط مستثناة من إيقاف التبويبات الخاملة، لأن فحص DOM في CEF لا يرى تشغيل WebView2.
- استمرار فحص طلبات محرك الوسائط بقواعد حجب الإعلانات وحماية الأسرة. لا إلغاء لفحص TLS أو العزل. منع تمرير بروتوكولات غير HTTP/HTTPS من محرك الوسائط إلى المتصفح.
- الروابط الجديدة والتحويلات تمر إلى CEF لتحديث شريط العنوان والسجل؛ لا عرض موقع مختلف خلف عنوان قديم.
- لا توصيل ملف WebView2 الدائم بالتصفح الخاص. تبقى الروابط في المحرك الخاص في هذه الحالة.
- جميع تعديلات 1.8.1 للغات والحماية والأداء موجودة في هذه الحزمة الكاملة.

## حدود الإصلاح

الصورة تظهر الانتقال إلى رابط مباشر ومشغّلاً عند 0:00؛ لا تحدد السبب وحدها. الإصدار السابق يستخدم CEF القياسي، ومحرك WebView2 كان مخصصاً لواتساب فقط. هذا التعديل يعالج مسار الملفات المباشرة؛ لا يضيف H.264 إلى مشغلات CEF داخل جميع المواقع.

لا ننقل كوكيز أو حسابات المواقع أو نختلق Referer بين المحركين. الروابط التي تحتاج جلسة الموقع أو Referer أو انتهت صلاحيتها قد لا تعمل بهذا المسار. الروابط بلا امتداد، HLS/DASH، DRM، التصفح الخاص، الترميزات غير المتاحة بالجهاز، والإطارات غير المتاحة للإضافة تحتاج فحصاً منفصلاً. زر إظهار التحكم لا يزيل طبقات الموقع ولا يصلح كل مشغّل مخصص، ولا يستطيع إضافة جودة غير موجودة في ملف واحد.

## ما تم التحقق منه

- نسخة الأساس تطابق ملفات GitHub للإصدار 1.8.1، commit 2152a615cd99163f81ab429f6a1102fc6511c553. نجح بناء Windows السابق رقم 37845006690.
- اختبارات محلية لمنطق توجيه روابط الوسائط، أدوات التحكم وعدم فرض التشغيل، رسائل الأخطاء واللغتين، عدم إيقاف تبويبات الوسائط، وصحة الحزمة والترجمات.
- أضيف اختبار أدوات HTML5 داخل صفحة CEF حقيقية إلى اختبارات Windows الموجودة؛ ينتظر تشغيل GitHub Actions للإصدار الجديد.
- لم يُشغّل بناء Windows أو فك ترميز الفيديو في WebView2 على هذه البيئة. نجاح اختبارات JavaScript لا يثبت نجاح فك الترميز. لا يُدّعى أن الموقع الموجود بالصورة اختُبر أو أن كل الفيديوهات أصبحت مدعومة.

## بعد رفع الملفات

ارفع **محتويات** الحزمة إلى جذر المستودع، مع مجلد `.github`، واستبدل الملفات القديمة. انتظر نجاح Build MaenBrowser Windows Setup، ثم نزّل Setup **1.8.2** من Artifacts وثبّته بعد إغلاق النسخة السابقة. رفع الكود لا يحدّث البرنامج المثبت تلقائياً.

اختبار Windows المطلوب قبل النشر العام:

1. رابط HTTPS مباشر صالح لملف H.264/AAC MP4: الصورة والصوت، التقديم، تغيير السرعة والتحكم بمستوى الصوت.
2. صفحة فيديو عادية: افتح الحماية ثم «إظهار أدوات الفيديو» وتحقق من عدم تشغيله تلقائياً.
3. الرجوع والتقدم وإعادة التحميل وتبديل التبويبات وإغلاق فيديو يعمل؛ تحقق من عدم بقاء صوت أو سطح فوق تبويب آخر.
4. ملف ممنوع بقواعد الأسرة، رابط منتهي، تنزيل مقصود وتصفح خاص. لا تعطيل للحماية لإجبار التشغيل.
5. تغيير لغة البرنامج وإعادة تشغيله؛ راجع رسائل المشغّل والواجهة. لغة مواقع الآخرين مستقلة.
6. اختبر الموقع الذي أبلغت عنه برابط جديد. إذا استمر 0:00، يلزم رابط الصفحة ورقم الإصدار لتحديد الاستجابة والترميز والجلسة؛ لا ترسل كلمة مرور أو رابطاً شخصياً ذا رمز وصول.
