# إصلاح التنزيل1.12.2

فك Changed-Files-Upload.zip وارفع محتوياته فوق نسخة1.12.1 الحالية في جذر
المستودع، مع .github وجميع المجلدات المرفقة. أو ارفع محتويات Full-Source.zip
للمصدر الكامل. اعمل Commit على main وانتظر نجاح GitHub ثم نزّل وثبّت Setup
الجديد1.12.2 من Artifacts. الوسمv1.12.2 ينشئ مسودة إصدار بعد نجاح الاختبارات.

الإصلاح يحافظ على طلب التنزيل الأصلي بدل إلغائه وإعادة فتحه، ويمنع تدخل كود
المتصفح بإخفاء نافذة التنزيل أو إغلاقها تلقائيًا. تنقل الصفحات العادية إلى
النافذة الأصلية بعد بدء مستند حقيقي، وتُترك نوافذ المرفقات تحت إدارة المحرك.
قد تبقى نافذة تنزيل مؤقتة فارغة؛ لا تُغلق أثناء النقل. لم نُعطّل الحماية أو
نفحص الملفات بالتنفيذ ولم نضف إعادة محاولات آلية لطلبات ذات استخدام واحد.

نجحت الاختبارات المحلية. أُضيفت إلى Windows CI حالات تنزيل POST وروابط
تحويل تشبه مرفقات المواقع؛ نتيجتها الفعلية تحتاج تشغيل GitHub بعد الرفع.

بعد التثبيت جرّب نفس الملف الذي كان يفشل. إن ظهر انقطاع، افتح صفحة التنزيلات
في MaenBrowser وانسخ رمز «السبب» الظاهر (مثل NETWORK_FAILED أو FILE_ACCESS_DENIED
أو USER_CANCELED). الرمز يفرّق خطأ الشبكة أو القرص أو الحماية عن إلغاء النافذة،
ولا يتطلب إرسال روابط التنزيل الخاصة أو الكوكيز أو كلمات المرور.
