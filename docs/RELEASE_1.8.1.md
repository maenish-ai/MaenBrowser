# MaenBrowser 1.8.1 — popup, language and performance corrections

## سبب العمل

الصورة المرسلة تعرض بقاء نافذة الحماية على التحميل ثم فشل طلب الاتصال. آخر إصدار 1.8.0 نجح في البناء والاختبارات القديمة:
https://github.com/maenish-ai/MaenBrowser/actions/runs/37838452027

الاختبارات القديمة أثبتت اتصال صفحة الإضافة وخدمتها، لكنها لم تختبر نافذة زر الشريط الفعلية. هذه النسخة تضيف اختبار تلك النافذة بدل الاعتماد على نجاح صفحة البداية وحده.

## التغييرات

- تمر طلبات واجهات التحكم إلى الخدمة الخلفية الخاصة بالإضافة؛ تتولى الخدمة الاتصال بنقطة الحماية المحلية. لا يُضاف خادم شبكة إلى المتصفح، ولا تُخفف سياسة CSP ولا التحقق من هوية مرسل الرسالة. تبقى أخطاء PIN ظاهرة ويستمر تطبيقها في الكود الأصلي.
- عند فشل الاتصال تتغير رسالة التحميل إلى حالة غير متاحة وزر إعادة اتصال. لا تُعرض حالة تشغيل الحجب قبل تأكيد الخدمة الأصلية.
- اختيار الإنجليزية أو العربية في الإعدادات، مع ترجمة جميع نصوص صفحات التحكم الثابتة وتنبيهاتها المعتادة، وضبط اتجاه الواجهة، وبيانات اسم الإضافة. يوجد اختبار يمنع النص العربي داخل قاموس الإنجليزية، وفحص لتغطية النصوص الثابتة وحفظ متغيرات الرسائل.
- يحفظ الاختيار في ملف محلي محدود بالقيمتين en/ar، ويضبط لغة CEF وWebView2 عند التشغيل التالي. تغيير اللغة لا يغيّر سياسة حماية الأسرة أو رمزها. إعدادات الأمان تبقى محمية كما كانت.
- تُحدّث صفحات التحكم المفتوحة عند تغيير اللغة. يجب إغلاق جميع نوافذ المتصفح وفتحه مجددًا لتغيير قوائم محرك Chromium بالكامل. صفحات المواقع والإضافات الخارجية وأزرار نوافذ ويندوز تتبع ترجمتها أو لغة النظام؛ هذا الإصدار لا يترجم المحتوى الخارجي تلقائيًا.
- أزيلت تأثيرات ضبابية الخلفية من بطاقات صفحة البداية، مع الإبقاء على تصميمها الأساسي.
- جرى تقليل تحليل الروابط غير الضروري في مسار الحجب، مع الحفاظ على ترتيب قواعد الأسرة والاستثناءات. تُفحص قائمة الإعلانات قبل تحليل رابط الصفحة للاستثناءات.
- فحص الخمول محدود بثلاث محاولات في كل دورة، مع تدوير الموضع لضمان فحص بقية المرشحين لاحقًا. تبقى استثناءات الصفحات النشطة والنماذج والصوت والمكالمات والتنزيلات كما هي.
- تُدمج أحداث تحديث قوائم التبويبات والتنزيلات خلال 150 مللي ثانية، ويؤجل تحديث واجهات التحكم المخفية حتى ظهورها. لا يوجد إغلاق مفاجئ للتبويبات أو خفض لجودة الفيديو.

## الاختبارات والحدود

نجح محليًا: فحص JavaScript، قواعد التبويبات والنطاقات، محاكاة ترميز ويندوز، تغطية نصوص الواجهات باللغتين، تمرير طلبات الواجهة إلى خدمة الإضافة مع حفظ أخطاء PIN، وفحص صياغة رأس C++ الخاص باللغة بمترجم يستهدف ويندوز.

لم يُبنَ 1.8.1 بواسطة MSVC في هذه البيئة ولم يعمل اختبار نافذة الشريط الجديدة هنا. يجب أن تنجح دورة GitHub Actions الجديدة قبل اعتماد Setup. نجاح 1.8.0 لا يغني عن اختبار هذه النسخة.

لا توجد نسبة تحسن أداء مقاسة ولا ادعاء بأنها الأخف. يمكن استخدام tools/measure-windows.ps1 على نفس الجهاز والمواقع قبل وبعد التثبيت. يستخدم واتساب محرك WebView2 إضافيًا، وقد يبقى حمله ملحوظًا على الأجهزة الضعيفة؛ لم نعطّل المحرك أو الصوت أو الكاميرا للتخفيف.

## الرفع والتجربة

الحزمة كاملة. فك الضغط وانسخ محتوياتها إلى جذر نسخة المستودع مع استبدال الملفات المطابقة والحفاظ على مجلد .git المحلي، ثم Commit وPush. تشمل الحزمة .github. يمكن الرفع عبر واجهة GitHub على دفعات إذا تجاوزت حد الملفات؛ اعتمد تشغيل Actions بعد اكتمال كل الدفعات.

بعد نجاح أحدث بناء، ثبّت Setup 1.8.1. افتح الدرع وجرب التشغيل والإيقاف والاستثناء، ثم Settings واختر اللغة. أغلق جميع النوافذ وافتح المتصفح لتطبيق لغة قوائم المحرك. جرّب بقاء الصوت والنماذج والمكالمات أثناء الخمول. لا تمسح ملفك الشخصي لأجل هذا التحديث.
